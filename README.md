## 🚀 Featured Projects

### 🛡️ Insurance Risk & Premium Decision Support System

An end-to-end machine learning application that predicts insurance charges and categorizes risk using customer demographic and lifestyle attributes.

- 📊 Compared Linear Regression, Random Forest, Gradient Boosting, and XGBoost.
- 🏆 Tuned XGBoost achieved an **R² score of 0.903** on the test set.
- ⚡ Built REST APIs using FastAPI for prediction, explanation, and history retrieval.
- 🗄️ Integrated PostgreSQL with Neon for persistent prediction history.
- 🖥️ Developed a Streamlit dashboard and deployed the application using Docker and Render.

**Tech:** Python, Scikit-learn, XGBoost, FastAPI, Streamlit, PostgreSQL, Docker, Render

🔗 [GitHub Repository](https://github.com/ArpitaTrip1402/Insurance-Risk-System)  
🚀 [Live API](https://insurance-risk-backend-pypl.onrender.com) | [API Documentation](https://insurance-risk-backend-pypl.onrender.com/docs)

- 🖥️ Interactive Streamlit interface

**Tech:** Python, LangChain, RAG, Gemini, FAISS, Streamlit
